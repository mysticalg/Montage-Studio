# Website artwork

Generated with the built-in imagegen tool for this project. No user media was used.

Final asset: `montage-hero.webp`, converted from a generated PNG for web delivery.

Prompt: “Standalone hero artwork for Montage Studio open-source video-editing website, matching a near-black cinematic editorial design with ivory type and cobalt-blue buttons. Wide 16:9 artwork only, no website text, no UI, no logos, no labels or watermarks. Elegant sculptural flowing loops of photographic film strips, containing sharp neutral mountains, ocean waves and city lights, suspended over a midnight black reflective surface. A luminous cobalt blue audio waveform threads through the ribbons, suggesting beat-synced video edits. Sophisticated real materials, realistic film translucency, sparse composition, beautiful directional studio lighting. Main ribbons occupy center and right, edges dissolve naturally into near-black; no people. Crisp beautiful cinematic render, not cluttered, dramatic depth.”

Design system: near-black `#080f16`, ivory `#f8f4ef`, cobalt `#087eff`; Manrope headings and DM Sans body; open four-column feature rail, horizontal download rows and generous spacing. Website UI remains HTML/CSS. The overview concept guided the hero, feature rail and platform download rows. Requirements, architecture choices and installation details use verified package information in place of concept placeholder claims.
