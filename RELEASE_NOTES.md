Montage Studio turns a folder of video clips and a music track into a finished montage on your own computer.

## Downloads

| Platform | Download |
| --- | --- |
| Windows 10/11 x64 | `Montage-Studio-windows-x64.zip` |
| macOS 13+ Apple Silicon | `Montage-Studio-macos-arm64.zip` |
| macOS 13+ Intel | `Montage-Studio-macos-x64.zip` |
| Linux x64, Ubuntu 22.04+ / compatible | `Montage-Studio-linux-x64.tar.gz` |

Extract the package; on macOS drag the app into Applications. Python and desktop runtimes are included. **Install FFmpeg and FFprobe separately.** Windows also needs WebView2; Linux system dependencies are listed in the included setup script. These are unsigned community builds; macOS packages are not notarized. SHA-256 sidecars accompany each archive.

## Features

Randomized clip rotation without repeats; 1–5000 clip selection; full-track matching; beat-aware edits; crossfades; eased ping-pong; fixed-length random excerpts; optical-flow interpolation; optional slow-zoom stills; ratio filtering; 720p through 2160p output; local GPU Real-ESRGAN; optional local Ollama captions; export thumbnails and folder access.

The optional Chrome/Edge X extension is included. Pair it explicitly with the local app to upload, post or save native X schedules. Rendering needs no social account. Extension queue processing stops on login, rate/security warnings and uncertain publication results.

No private media, accounts, databases, saved schedules or pairing credentials are included.
